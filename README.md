# Pomodoro+

A single-page Pomodoro timer with task tracking, built as a self-contained `index.html` — no build step, no dependencies.

## Features

- Focus / short break / long break timer modes (25 / 5 / 15 minutes)
- Automatic long-break scheduling every 4 focus sessions
- Task list with per-task pomodoro counts and an "active task" selector
- Daily, streak, and total session stats
- Data persisted locally via `localStorage` — nothing leaves your browser
- Chime + browser notification when a session ends
- Light/dark theme support (follows system preference)

## Usage

Open `index.html` in any modern browser. That's it — no install, no server required.
